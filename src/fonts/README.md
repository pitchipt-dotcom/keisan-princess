# 同梱フォント

外部（Google Fonts）へ 通信しない ように、フォントを アプリの 中に 入れています。
ファイルは Google Fonts（fonts.gstatic.com）が 配っている woff2 と 同じもので、
`fonts.css` は Google Fonts の CSS の URL だけを 相対パスに 書きかえた ものです。

| 書体 | 太さ | ライセンス |
|---|---|---|
| Mochiy Pop One | 400 | SIL Open Font License 1.1（mochiypopone/OFL.txt） |
| Zen Maru Gothic | 500・700・900 | SIL Open Font License 1.1（zenmarugothic/OFL.txt） |
| Yomogi | 400 | SIL Open Font License 1.1（yomogi/OFL.txt） |

取得元 CSS: `https://fonts.googleapis.com/css2?family=Mochiy+Pop+One&family=Zen+Maru+Gothic:wght@500;700;900&family=Yomogi&display=swap`（2026年11月）
