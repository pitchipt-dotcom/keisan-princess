# はじめて あそんだ 日（firstPlayedAt）

セーブ（`kukumajo:save:v1`）と バックアップコードに `firstPlayedAt`（ISO の 日時の 文字列）を 入れる。ロジックは `src/firstPlayed.js`、テストは `tests/firstPlayed.test.mjs`（`npm test`）。

- はじめて ひらいた とき：今の 日時（さいしょに 保存する とき セーブに 入る）
- すでに ある セーブで まだ 無い とき：セーブの 中の きろくで いちばん古い 日の 0時（2年生 まいにち けいさんの history・calendar・lastDate、おはなし もんだいの storyFeed、3年生 毎日計算の history・lastDate）。きろくが 無ければ 今の 日時。読みこんだ ときに すぐ 保存する
  - まちがいノートの due（これからの 日）と lastTicketWeek（週の 月曜日）は つかわない
- 一度 入ったら 上書きしない
- バックアップコードの 読みこみ（「さいしょから」の 取り消しも）：今の 値と コードの 値の 古い ほうを のこす。`firstPlayedAt` の ない 古い コードは、コードの 中の きろくの いちばん古い 日を つかう（きろくも 無ければ 今の 値の まま）
- 「さいしょから」では けさない。「データを すべて けす」では きえて、つぎに ひらいた 日が あたらしい はじめた 日に なる
- 画面：おうちのひとメニューの いちばん下に 小さく「はじめた日: 2026年11月21日」

将来の 予定：この 日付より 前から あそんでいる 人には、有料の 機能も ひらく（よてい）。

注意：バックアップコードは かぎの ない base64 の JSON なので、`firstPlayedAt` は 書きかえられる。有料の 機能を ひらく 判定に つかう ときは、コードの 中の 値を そのまま 信じない しくみ（サーバーでの 記録・署名など）を べつに 考える。
