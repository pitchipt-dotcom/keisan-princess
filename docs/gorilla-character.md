# 4人目：ゴリラの プリンセス ／ ゴリラの プリンス

モードの ながれ・問題・ごほうびの しくみは かえず、キャラを 1人 ふやした だけ。性格は「力もちで やさしい、たよれる」。

- キャラ id：`gorilla`（セーブの `character`、`collection.gorilla` など）。さいしょから えらべる
- 名前（仮）：プリンセスは `ゴリラ姫(仮)`（`src/App.jsx` の `CHARACTERS`）、プリンスは `ゴリラ王子(仮)`（`src/theme.js` の `THEMES.prince.chars.gorilla`）。きまったら この 2か所を さしかえる
- テーマ色：`#8FCB8B`（もりの みどり）
- コーデ：アイテム id `g_*` を 16こ（頭4・ふく2・あし2・もちもの4・かざり4）。ものがたりの イベント（4・8・12・16こ）は 3人と 同じ
- 正解の しゅんかん（まいにち けいさん・九九などの ふつうの プレイ）だけ ドラミング（`.kk-drum`）。タイトル・きせかえ では ゆれない。動きを へらす 設定では 止まる
- おはなし もんだいの 問題文・ようせいの くに・ものがたりの 場面の 絵は かえていない
