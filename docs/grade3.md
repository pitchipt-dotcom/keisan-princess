# 3年生（わり算・小数・分数・毎日計算）

メニューの「1ねんせい」「2ねんせい」の つぎに「3年生」を 追加（ボタンの 字は 漢字。1・2年生の 字は そのまま）。
あわせて、2年生の「まいにち けいさん」を チャレンジから「2ねんせい」の さいしょへ うつし、チャレンジの 名前を「かたち・かさ チャレンジ」に した
（中身は ようせいの くに・ドラゴン。グループの id は "challenge" の まま なので、セーブの menuGroup は そのまま つかえる）。

- わり算・小数・分数：① 図で うごかして わかる → ② 10もん → ③ けっか。ごほうびは ★（→ コーデ）だけ。ドラゴンは そだたない
  - わり算：わかったら 数字で こたえて いい。クッキーを くばるのは わからない ときの 手つだい
  - 小数：1Lますの 目もりは 0.1L ごと（数字つき）。線で 長めに 止まり、はなすと 0.1L に そろう
  - 分数：ケーキ・ピザは はじめから 切れめ つき。「4分の3に なるように ぬろう」→「4つに 分けた うちの 3つぶん」。大きさくらべは 1/2 と 1/4、2/4 と 1/2（おなじ）
- こたえは 三択から。10もんで 8もん いじょう（1かいめで）せいかいが 2かい つづくと 入力に ステップアップ（スタート画面で 三択に もどせる）
- 毎日計算（3年生）：3年生 6（しき 4 ＋ よみとりチェック 2）／ 2年生の まいにち けいさん 3 ／ ようせいの くに 1。よみとりチェックは 2年生と 同じ 画面で、中身は わり算・小数・分数（`src/grade3/yomi3.js`）。ドラゴン・れんぞく日数・スタンプ・その日の ボーナス★ は 2年生と 共通（そだつのは 1日1かい）
- セーブ：`grade3`（`src/grade3/g3.js` の `normalizeGrade3`）。バックアップコードに 入る。`grade3` の ない 古い コードでも さいしょからに なるだけで エラーに ならない

## 絵（本番。Moss-image）

`src/assets/grade3/` に おいて ある。プリンス用が ほしい ときは `<名前>_prince.webp`（無ければ 共通の 絵）。絵が 無い ときは かりの SVG に もどる。
画像の 中に 文字は 入れない。背景は 透過。

| ファイル | サイズ | 中身 |
|---|---|---|
| `cookie.webp` | 128×128 | チョコチップの クッキー（白い 背景を 透過に） |
| `plate.webp` | 256×176 | 白い おさら（はいいろの 背景と 下の かげを 透過に） |
| `cookie-jar.webp` | 192×216 | クッキーの 入った ガラスびん（ふたは ピンク） |
| `cake-top.webp` | 512×512 | まうえから 見た ホールケーキ（いちご 8こ・クリーム 8こ。いちごが 0°・45°…） |
| `pizza-top.webp` | 512×512 | まうえから 見た ピザ |

- ケーキ・ピザは まるの 中心を 画像の 中心に あわせて くりぬいた。まるの 半径は 画像の 半分の 0.985（ケーキ）・0.992（ピザ）。`Figures.jsx` の `ART_FILL` で 切れめの 線と まるを ぴったり かさねて いる
- ケーキの 切れめは 11.25° まわして ある：いちごと クリームの あいだに 線が くるので、2・4・8 に 分けた ときに かざりの とちゅうで 切れない（3・5 などは かざりに かかる）
- ぬった きれは 上から 半とうめいの 色（ケーキ ピンク、ピザ 青）
- ジュースの 入れ物（1Lます・0.1Lます）と 展開図・1Lますの 図は、ようせいの くにと 同じく SVG で かく
