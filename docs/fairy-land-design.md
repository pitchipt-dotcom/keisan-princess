## キャラクターと妖精

- 3人のプリンセス（まじょのルナ／にんぎょのマリン／プリンセスのロゼ。`CHARACTERS` の `id` は witch / mermaid / princess）に、それぞれ1人ずつ妖精がつく。
  - 妖精はエリアの案内役。ヒントのせりふは妖精が言う。
  - 妖精の名前・見た目は実装時に決める。絵はドラゴンと同じく MOSS-Image で作り、`tools/art/process.py` で背景を抜く。絵が読めないときは絵文字で代わりに表示する（ドラゴンと同じ方式）。
- 遊んでいるキャラクター（`characterId`）の妖精が出る。キャラを切り替えると妖精も切り替わる。

## 報酬（ドラゴン育成とは別の系統）

- 妖精ごとに「なかよし度」を持つ。エリアのお題を1つクリアすると +1。
- なかよし度が決まった数に届くと、妖精の国の地図のマスが1つ開く（新しいエリア、または飾り）。
- ドラゴンの「そだちポイント」、星のかけら、おやすみチケット、ずかんとは混ぜない。
  - 星のかけらを渡すかどうかは実装時に決める。渡す場合も、まいにち けいさんより少なくする。
- 地図は3人で共通にするか、妖精ごとに別にするかは未決（下の「決めること」）。

## セーブデータ（案）

既存の `kukumajo:save:v1` に `fairy` キーを1つ足すだけにし、ほかのキーは触らない。

```js
fairy: {
  friendship: { witch: 0, mermaid: 0, princess: 0 },   // なかよし度
  map: ["tsumiki"],                                     // 開いたエリア
  cleared: { "tsumiki:3": "2026-12-01" },               // クリアしたお題 → 日付
}
```

- 読み込み時に `normalizeFairy()` で、キーが無い古いセーブを補う（`normalizeDaily` と同じ考え方）。
- バックアップコード（`buildSnapshot` / `applySnapshot`）に `fairy` を入れる。
- おうちのひとレポートに出すかどうかは、エリアが2つ以上できてから決める。

## エリア

### 1. つみきの森（立方体・直方体）

- 立方体／直方体のつみきを指でドラッグして回す。
- マス目の上でつみきを転がし、つみきの底の面が通ったマスに色を塗る。
- お題の例
  - 「この 色の マスを ぜんぶ ぬろう」（ゴールのマスまで転がす）
  - 「直方体を ころがすと、何マス すすむ？」
- 学ぶこと：面の数（6つ）、向かい合う面、辺や頂点の数（2年生の「はこの形」）。
- 技術
  - Three.js を使う想定。ファイルが大きい（gzip で 150KB 前後）ので、エリアに入ったときだけ `import()` で読み込み、ほかのモードの起動を遅くしない。
  - 転がす動きは「辺を軸に90°回す」アニメーションとして自分で書き、物理エンジンは使わない。
  - 回転はドラッグのみ（2本指での操作は使わない）。PWA／iPad Safari で確認する。
  - WebGL が使えない端末では「この そうちでは あそべないよ」と出して戻す。

### 2. ジュースの泉（かさ：L・dL）

- 1Lますから dLますへジュースを注ぐ（ますを傾けるドラッグ、またはボタン長押し）。
- 妖精たちに同じ量ずつ分ける。
- お題の例：「1L6dL を 2人に 同じ かさずつ」「7dL ＋ 5dL は 何L何dL？」
- 学ぶこと：1L＝10dL、くり上がり・くり下がり（フェーズ1の単位の問題とつながる）。
- 技術：SVG と CSS のアニメーションで作る（Three.js は使わない）。水位は dL 単位でぴったり止める。

### 3. ますめの花畑（広さ）

- 花畑の図形のうち、三角の部分をドラッグで動かしてくっつけ、四角にする。
- 広さを「ますの数」で数える。
- お題の例：「はみ出した 三角を うごかして、ぜんぶで 何ます？」
- 学ぶこと：広さの考え方（面積の前段階）、図形を移して形を変えても広さは同じこと。
- 技術：SVG のマス目に、ピースを吸い付く位置へスナップさせる。ピースの回転は 90° 単位のボタンにする。
