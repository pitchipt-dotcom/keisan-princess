# 妖精の国 探検モード — 設計メモ（フェーズ2以降）

フェーズ1（まいにち けいさんの「よみとりチェック」）の次に作るモードの設計メモ。
エリアは1つずつ実装し、1エリアごとにPRを分ける。

- 実装済み：土台（`src/fairy/fairy.js`・地図画面・セーブ・バックアップコード）と「つみきの森」の立方体・直方体・変わった形の盤（`feature/fairy-tsumiki`）
- 未実装：つみきの森の面の向き、ジュースの泉、ますめの花畑

## ねらい

- 2年生の「図形・かさ・広さ」を、手で動かして体で覚える。
- 計算ドリルとは違う「さわって考える」時間にする。時間は計らない。間違えてもバツで止めない（まいにち けいさんと同じ方針）。

## キャラクターと妖精

- 3人のプリンセス（まじょのルナ／にんぎょのマリン／プリンセスのロゼ。`CHARACTERS` の `id` は witch / mermaid / princess）に、それぞれ1人ずつ妖精がつく。
  - 妖精はエリアの案内役。ヒントのせりふは妖精が言う。
  - 妖精の名前・見た目は実装時に決める。絵はドラゴンと同じく MOSS-Image で作り、`tools/art/process.py` で背景を抜く。絵が読めないときは絵文字で代わりに表示する（ドラゴンと同じ方式）。
- 遊んでいるキャラクター（`characterId`）の妖精が出る。キャラを切り替えると妖精も切り替わる。

## 報酬（ドラゴン育成とは別の系統）

- 妖精ごとに「なかよし度」を持つ。エリアのお題を1つクリアすると +1。
- なかよし度が決まった数に届くと、妖精の国の地図のマスが1つ開く（新しいエリア、または飾り）。
- ドラゴンの「そだちポイント」、星のかけら、おやすみチケット、ずかんとは混ぜない。
  - 星のかけらを渡すかどうかは実装時に決める。渡す場合も、まいにち けいさんより少なくする。
- 地図は3人で共通にするか、妖精ごとに別にするかは未決（下の「決めること」）。

## セーブデータ（案）

既存の `kukumajo:save:v1` に `fairy` キーを1つ足すだけにし、ほかのキーは触らない。

```js
fairy: {
  friendship: { witch: 0, mermaid: 0, princess: 0 },   // なかよし度
  map: ["tsumiki"],                                     // 開いたエリア
  cleared: { "tsumiki:3": "2026-12-01" },               // クリアしたお題 → 日付
}
```

- 読み込み時に `normalizeFairy()` で、キーが無い古いセーブを補う（`normalizeDaily` と同じ考え方）。
- バックアップコード（`buildSnapshot` / `applySnapshot`）に `fairy` を入れる。
- おうちのひとレポートに出すかどうかは、エリアが2つ以上できてから決める。

## エリア

### 1. つみきの森（立方体・直方体）

- 立方体／直方体のつみきを指でドラッグして回す。
- マス目の上でつみきを転がし、つみきの底の面が通ったマスに色を塗る。
- お題の例
  - 「この 色の マスを ぜんぶ ぬろう」（ゴールのマスまで転がす）
  - 「直方体を ころがすと、何マス すすむ？」
- 学ぶこと：面の数（6つ）、向かい合う面、辺や頂点の数（2年生の「はこの形」）。
- 技術
  - Three.js を使う想定。ファイルが大きい（gzip で 150KB 前後）ので、エリアに入ったときだけ `import()` で読み込み、ほかのモードの起動を遅くしない。
  - 転がす動きは「辺を軸に90°回す」アニメーションとして自分で書き、物理エンジンは使わない。
  - 回転はドラッグのみ（2本指での操作は使わない）。PWA／iPad Safari で確認する。
  - WebGL が使えない端末では「この そうちでは あそべないよ」と出して戻す。

### 2. ジュースの泉（かさ：L・dL）

- 1Lますから dLますへジュースを注ぐ（ますを傾けるドラッグ、またはボタン長押し）。
- 妖精たちに同じ量ずつ分ける。
- お題の例：「1L6dL を 2人に 同じ かさずつ」「7dL ＋ 5dL は 何L何dL？」
- 学ぶこと：1L＝10dL、くり上がり・くり下がり（フェーズ1の単位の問題とつながる）。
- 技術：SVG と CSS のアニメーションで作る（Three.js は使わない）。水位は dL 単位でぴったり止める。

### 3. ますめの花畑（広さ）

- 花畑の図形のうち、三角の部分をドラッグで動かしてくっつけ、四角にする。
- 広さを「ますの数」で数える。
- お題の例：「はみ出した 三角を うごかして、ぜんぶで 何ます？」
- 学ぶこと：広さの考え方（面積の前段階）、図形を移して形を変えても広さは同じこと。
- 技術：SVG のマス目に、ピースを吸い付く位置へスナップさせる。ピースの回転は 90° 単位のボタンにする。

## つみきの森 — 実装メモ

- ルール（テストと同じ）：つみきが紙についたマスに色がつく。盤の外には転がせない。一度色がついたマスにはもう転がせない。
- つみき：立方体（さいころ）と直方体（2こつなげた積み木）。直方体は「たっている（紙につくのは1マス）／ねている（2マス）」を盤のすぐ下に絵とことばで出す。ねているときは紙についた2マスとも同じ番号で色がつく。記録のチップにも たつ／ねる の小さな絵。
- 画面：上から「段階名・つみきの種類」→ **ゴールの帯**（妖精のセリフとは別の黄色い帯。段階1は「のこり ○マス」、段階3は「ぬる マス ○こ」も出す）→ 妖精 → 盤（メインは斜め上から見た3D、横に小さく真上から見た2D。小さい方をタップで入れかわる。WebGLが無い端末は2Dだけ）→ 手順のカード → ボタン → 記録。
- Three.js は妖精の国に入ったときだけ読み込む（`React.lazy`）。ほかのモードの起動は遅くならない。
- 転がす向き：おく・てまえ・みぎ・ひだり。ボタンとスワイプ（上＝おく）。転がるときは へりを軸に90°回る 0.3秒のアニメーション。
- 段階
  1. じゆうに ころがす — ゴール「ぜんぶの マスに 色を つけよう！」。どこにも転がせなくなったら「いきどまり」と言い、「はじめから」で やり直す。1セット3つの盤。
  2. よそうして ころがす — ゴール「ころがすと 色が つく マスを ぜんぶ えらぼう」。最初の1回だけ妖精が「さいごの マスだけじゃなくて、とちゅうの マスも ぜんぶだよ」と言う。はじめのマスは最初から①で色つき（選ばなくてよい）。「えらんだ マス 2 / 3こ」を出す。指示は ボタンと違う見た目の **おてがみカード**（「この じゅんばんで ころがすよ」＋「① おく ② みぎ ③ みぎ」）。予想が終わるまで向きのボタンは出さない。転がしている間は、いまの手順を光らせる。答え合わせは あたり（緑）／たりない（ピンクの点線と「!」）／よけい（グレーの点線の〇）で色分けし、数も出す。
  3. もようから かんがえる — ゴール「★の つみきを ころがして、点線の マスを ぜんぶ ぬろう」。スタートのつみきに「スタート」の札（3Dと2Dの両方）。子どもが入れた順番は **きみの じゅんばん**（番号つきの別の枠）に並べ、確かめるときは いまの手順を光らせる。うまく転がせなかった手はピンクで示し「きみの じゅんばんの ③（おく）で…」と言う。「ゴールから もどる」は点線のマスの上だけを逆に転がり、戻った手順を記録に並べる。戻れたら逆の順番が答えとして出て、そのまま確かめられる。
- 盤の形：正方形のほか L字・T字・階段・すき間（あな）のある形。手では作らず、**スタートから実際に転がして（一度通ったマスは通らない）通ったマスを盤にする**ので、ぜんぶぬれる転がし方が必ずある。立方体は 5×5、直方体は 6×6 の中で作る。
  - 段階1：作った盤をそのまま出す（ほかの順でも ぬれることがあるし、行き止まりにもなる）。立方体の2問目は 3×3 の正方形のことがある。
  - 段階2：転がした道の先をさらに伸ばして盤にし、指示はその途中まで（盤をぜんぶ選べば正解、にはならない）。立方体の1問目は 3×3 の正方形のことがある。
  - 段階3：盤＝点線のマス。ぬれる順番が1とおりだけの盤だけを使い、「ゴールから もどる」でどう戻っても行き止まりにならない盤だけを使う（立方体は さらに「1本道」で、戻れる向きがいつも1つ）。
- むずかしさ（1セットの 1・2・3問目）：マスの数と曲がる回数で3段階（`LEVELS`、tsumiki.js）。

  | | 段階1 マス／曲がる | 段階2 マス／指示の曲がる | 段階3 マス／曲がる |
  |---|---|---|---|
  | 立方体 Lv1 | 5〜6／1〜2 | 5〜9／1〜2 | 4〜5／1〜2 |
  | 立方体 Lv2 | 7〜9／2〜4 | 6〜9／1〜3 | 6〜7／2〜4 |
  | 立方体 Lv3 | 10〜13／4〜9 | 8〜11／2〜5 | 8〜10／3〜7 |
  | 直方体 Lv1 | 6〜9／1〜2 | 8〜13／1〜2 | 6〜7／1〜2 |
  | 直方体 Lv2 | 9〜12／2〜4 | 9〜14／1〜3 | 8〜10／2〜4 |
  | 直方体 Lv3 | 12〜16／3〜7 | 11〜16／2〜4 | 11〜14／3〜6 |

- 自動テスト（`tsumiki.js` の純粋関数）：作った盤はすべて、作ったときの道を使わないソルバー（`solveCover`）で「ぜんぶぬれる転がし方がある」ことを確かめ、その転がし方を1手ずつ自分でたどって確認する（立方体・直方体 それぞれ 27000問）。指示と色がつくマスの一致、「さいごのマスだけ選ぶ」と足りないマスが出ること、段階3の答えが1とおりで ゴールから戻ると必ずスタートに着くことも確かめる。
